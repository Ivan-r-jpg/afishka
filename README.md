# Afishka

**Afishka — афіша подій України.** Це навчальний вебпроєкт, створений у межах дисципліни «Клієнтські технології Web-програмування». Він демонструє каталог подій із базовою інформацією про дати, ціни й місця проведення.

## Поточний стан проєкту

Проєкт є статичним прототипом із п'яти HTML-сторінок і окремою таблицею стилів:

- **Головна** (`index.html`) — каталог із шістьма картками подій, пошук, категорії та сортування.
- **Про подію** (`details.html`) — детальна сторінка благодійного концерту «Жадан і Собаки», розклад, реєстрація та відгуки.
- **Про Afishka** (`about.html`) — опис сервісу, можливості, відео з субтитрами та FAQ.
- **Адміністрування** (`admin.html`) — таблиця подій і форма додавання нової події.
- **Редагування події** (`admin-edit.html`) — навчальна форма редагування однієї події.

Сторінки мають спільне адаптивне оформлення у [`css/main.css`](css/main.css): каскадні шари, дизайн-токени, світла й темна теми за налаштуваннями браузера, стилі таблиць, форм і навігації. Також використано семантичну HTML-розмітку, хлібні крихти, навігаційні посилання та видимий індикатор фокусу.

Для зображень використано `srcset`, `sizes` та `<picture>` із версіями PNG і WebP для адаптивного завантаження. Відео на сторінці «Про Afishka» має формати MP4 і WebM, постер і субтитри у WebVTT.

Форми та елементи пошуку наразі є HTML-прототипами: браузер перевіряє валідність полів, але пошук, сортування, додавання й редагування не зберігаються й не обробляються сервером. Файл `script.js`, на який посилаються сторінки, у проєкті ще не створено. Даних у базі даних теж немає.

## Технології

- HTML5 і семантична розмітка
- CSS із каскадними шарами, змінними та адаптивними стилями
- Адаптивні зображення за допомогою `srcset`, `sizes` і `<picture>`
- Вбудоване HTML-відео, субтитри WebVTT та альтернативні формати відео
- Нативна перевірка форм браузером

## Запуск

Відкрийте `index.html` у браузері. Встановлення залежностей або збірка не потрібні. Інтернет для відкриття сторінок не потрібен; відео та зображення завантажуються з локальних файлів проєкту.

## Модель даних

Опис полів події для форм додавання й редагування наведено у [`docs/dictionary.md`](docs/dictionary.md). Словник охоплює артикул, назву, категорію, постер, опис, ціну, дату, місце проведення та статус наявності квитків.

## Запланований розвиток

1. Додати JavaScript для пошуку, фільтрації та сортування подій.
2. Реалізувати додавання, редагування й видалення подій.
3. Підключити сховище даних або бекенд/API.
4. Додати перевірку введених даних на боці сервера та автентифікацію адміністраторів.
5. Удосконалити адаптивність і автоматизоване тестування інтерфейсу.
