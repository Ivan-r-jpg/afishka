# Afishka

**Афіша подій України** — навчальний вебпроєкт студента спеціальності «Комп’ютерні науки», створений у межах дисципліни **«Клієнтські технології Web-програмування»**.

Afishka збирає в одному місці концерти, вистави, лекції, виставки та інші події. Ідея проєкту — зробити пошук цікавого дозвілля в Україні простим і зручним.

## Поточний стан

Зараз реалізована базова HTML-структура сторінки. Вона містить навігацію, поле пошуку, категорії та сортування, картки подій з описами, датами й цінами, а також форму додавання події та контактну інформацію.

Пошук, фільтри, сортування і форма поки є лише елементами інтерфейсу: стилі та JavaScript-функціональність ще не реалізовані. Проєкт розвиватиметься поступово.

## Технології

- HTML5 і семантична розмітка
- Адаптивні зображення через `srcset` і `sizes`
- CSS та JavaScript — заплановані наступними етапами

## Запуск

Відкрийте `index.html` у браузері. Додаткове встановлення залежностей не потрібне.

## Подальший розвиток

1. Створити адаптивне оформлення сторінки.
2. Додати пошук, фільтрацію та сортування подій.
