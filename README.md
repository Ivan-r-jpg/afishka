# Afishka

**Afishka** — статичний прототип афіші подій України для навчального курсу
«Клієнтські технології Web-програмування». Проєкт демонструє каталог подій,
детальну інформацію, відео-презентацію та макети адміністративних сторінок.

## Сторінки проєкту

- [`index.html`](index.html) — головний каталог із шістьма картками подій,
  пошуковою формою, фільтрами за категоріями та вибором сортування.
- [`details.html`](details.html) — детальна сторінка благодійного концерту:
  опис, характеристики, розклад, секція реєстрації та відгуки.
- [`about.html`](about.html) — опис можливостей сервісу, відео з субтитрами та
  FAQ у вигляді нативних елементів `<details>`.
- [`admin.html`](admin.html) — макет адміністративної панелі зі списком подій,
  посиланнями редагування та формою додавання.
- [`admin-edit.html`](admin-edit.html) — макет редагування події із формою,
  попереднім переглядом постера та збереженням поля артикулу.

Усі сторінки мають спільну шапку, навігацію, підвал, favicon та єдиний файл
стилів [`css/main.css`](css/main.css).

## Поточні можливості

- Семантична HTML5-розмітка та навігація з атрибутом `aria-current`.
- Адаптивне оформлення з Flexbox, дизайн-токенами й окремими BEM-класами.
- Світла та темна теми за налаштуваннями системи через `prefers-color-scheme`.
- Каскадні шари CSS у порядку `reset`, `base`, `components`, `utilities`.
- Видимий індикатор фокусу клавіатурної навігації та клас
  `.visually-hidden`.
- Адаптивні зображення через `srcset`, `sizes` і `<picture>`, а для постерів —
  також альтернативи PNG/WebP.
- Відео в форматах MP4 і WebM із постером і субтитрами WebVTT.
- Таблиці розкладу й адміністративний список із адаптивною обгорткою.
- Нативна перевірка форм браузером з підтримкою `required`, `pattern`,
  числових меж і мінімальних довжин тексту.

## Механіка інтерфейсу

На поточному етапі проєкт є статичним HTML/CSS-прототипом:

- пошук, фільтри й сортування не змінюють список подій;
- кнопки додавання та редагування не змінюють дані;
- форми не надсилаються на сервер і не зберігають інформацію;
- скрипт `script.js` поки не створено, і сторінки не мають динамічної логіки;
- бази даних, API та авторизації адміністратора немає.

## Структура даних

Поля для подій описані у [`docs/dictionary.md`](docs/dictionary.md):

- артикул `eventCode`;
- назва `title`;
- категорія `category`;
- постер `poster`;
- опис `description`;
- ціна `ticketPrice`;
- дата і час `eventDate`;
- місце проведення `location`;
- статус наявності квитків `inStock`.

## Технології

- HTML5;
- CSS3: каскадні шари, custom properties, медіазапити та адаптивна верстка;
- WebP, PNG і WebVTT;
- нативна валідація HTML-форм.

## Запуск

Залежності та збірка не потрібні. Відкрийте [`index.html`](index.html) у
браузері або запустіть локальний статичний сервер, наприклад:

```powershell
python -m http.server 8080
```

Після запуску серверу відкрийте <http://localhost:8080/>.

## Пріоритети подальшого розвитку

1. Додати `script.js` для пошуку, фільтрації та сортування.
2. Реалізувати додавання, редагування й видалення подій.
3. Підключити сховище даних або бекенд/API.
4. Додати перевірку даних на сервері та автентифікацію адміністраторів.
5. Додати автоматизовані перевірки верстки та інтерактивності.
