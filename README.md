# Afishka

**Afishka — афіша подій України.** Це навчальний вебпроєкт, створений у межах дисципліни «Клієнтські технології Web-програмування». Він демонструє каталог подій із базовою інформацією про дати, ціни й місця проведення.

## Поточний стан проєкту

Проєкт містить три статичні HTML-сторінки:

- **Головна** (`index.html`) — каталог із шістьма картками подій, елементами пошуку, категоріями, сортуванням і формою для введення нової події.
- **Про подію** (`details.html`) — опис благодійного концерту «Жадан і Собаки», його подробиці та розклад.
- **Про Afishka** (`about.html`) — опис сервісу, FAQ та відео з субтитрами.

У сторінках використано семантичну HTML-розмітку, навігаційні посилання, адаптивні зображення різних розмірів, а для фотографії концерту — також формати WebP і PNG. Відео доступне у форматах MP4 та WebM.

Пошук, фільтрація, сортування та збереження події поки що не реалізовані: відповідні елементи форми є частиною інтерфейсу, але не виконують цих дій. Файли стилів і JavaScript ще не створені; наявні HTML-сторінки містять посилання на `style.css` і `script.js`, які зараз не підключають оформлення чи функціональність.

## Технології

- HTML5 і семантична розмітка
- Адаптивні зображення за допомогою `srcset`, `sizes` і `<picture>`
- Вбудоване HTML-відео, субтитри WebVTT та альтернативні формати відео

## Запуск

Відкрийте `index.html` у браузері. Встановлення залежностей або збірка не потрібні. Інтернет для відкриття сторінок не потрібен; відео та зображення завантажуються з локальних файлів проєкту.

```text
├── about.html
├── details.html
├── favicon.ico
├── images/

├── media/
│   ├── event1.mp4
│   ├── event1.webm
│   └── event1.vtt
└── README.md
```

## Запланований розвиток

1. Додати адаптивне оформлення сторінок.
2. Реалізувати пошук, фільтрацію та сортування подій.
3. Додати обробку форми створення подій і перевірку введених даних.
4. Удосконалити доступність і взаємодію з інтерфейсом.
