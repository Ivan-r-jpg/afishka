# Словник полів моделі елемента каталогу (Подія)

Цей словник описує структуру даних для картки події (елемента каталогу), яка
використовується у формах адміністратора для додавання та редагування.

| Призначення поля (Label) | Назва поля (атрибут `name`) | Тип даних (JS/DB) | Елемент керування (HTML)        | Обмеження валідації (Attributes)                               |
| :----------------------- | :-------------------------- | :---------------- | :------------------------------ | :------------------------------------------------------------- |
| **Ідентифікатор події**  | `eventId`                   | `number`          | `<input type="hidden">`         | Використовується лише у формі редагування для вказівки ID.     |
| **Артикул події**        | `eventCode`                 | `string`          | `<input type="text">`           | `required`, `pattern="^AF-\d{4}$"`                             |
| **Назва події**          | `title`                     | `string`          | `<input type="text">`           | `required`, `minlength="5"`, `maxlength="100"`                 |
| **Категорія**            | `category`                  | `string`          | `<select>` з `<option>`         | `required` (перший `<option>` має порожній `value=""`)         |
| **Постер (зображення)**  | `poster`                    | `File` / `string` | `<input type="file">`           | `accept="image/png, image/jpeg, image/webp"`                   |
| **Опис події**           | `description`               | `string`          | `<textarea>`                    | `minlength="20"`, `maxlength="1000"`                           |
| **Ціна квитка (грн)**    | `ticketPrice`               | `number`          | `<input type="number">`         | `required`, `min="0"`, `max="10000"`, `step="0.01"`            |
| **Дата проведення**      | `eventDate`                 | `datetime`        | `<input type="datetime-local">` | `required`, `min="2026-01-01T00:00"`, `max="2027-12-31T23:59"` |
| **Місце проведення**     | `location`                  | `string`          | `<input type="text">`           | `required`, `minlength="5"`, `maxlength="120"`                 |
| **Квитки у продажу**     | `inStock`                   | `boolean`         | `<input type="checkbox">`       | Статус активності (надсилається `value="yes"`, якщо обрано)    |

> **Примітка:** Службові поля, такі як згода з правилами (`agreement`), не
> включені до словника моделі, оскільки вони не є частиною характеристик самої
> події в базі даних.
